# NIST RMM MCP

A Model Context Protocol (MCP) server that provides access to the National Institute of Standards and Technology (NIST) Resource Metadata Management (RMM) system.

## Purpose

The NIST RMM system is a comprehensive repository that catalogs NIST's scientific data resources, including:

- Research datasets and experimental data
- Reference materials and calibration standards  
- Software tools and analysis utilities
- Publications and technical documentation
- Standard Reference Data (SRD) collections

## Uses in NIST?

NIST produces some of the world's most trusted scientific data across domains like:

- **Manufacturing & Materials** - Additive manufacturing, materials characterization
- **AI & Cybersecurity** - Machine learning datasets, trojan detection, privacy research
- **Public Safety** - Emergency response technologies, communications research
- **Physics & Chemistry** - Precision measurements, quantum science
- **Information Technology** - Software testing, computational modeling

This MCP enables AI assistants to discover and access NIST's validated, high-quality datasets programmatically.

## Key Features

- **Search** NIST's entire data repository by keywords, topics, and research domains
- **Browse** hierarchical research taxonomy across 30+ scientific domains
- **Access** detailed metadata including authors, formats, DOIs, and download links
- **Discover** related datasets, tools, and publications
- **Explore** data schemas and available search parameters
